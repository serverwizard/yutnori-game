# 우리 반 윷놀이 🎲

초등학교 3학년 교실용 윷놀이 웹 게임. 선생님이 방을 만들고, 학생들은 **QR 코드**로 들어와 **반별로 독립된 게임방**에서 팀 대결을 합니다. 로그인·계정 없이 동작하고, 무료 서버(Render 등)에 한 번 배포하면 학교 어디서든 쓸 수 있습니다.

## 두 가지 모드

| 모드 | 언제 | 주소 |
|---|---|---|
| **🥢 윷만 던지기** | 윷판·말은 실물로 놀고, 윷 던지기만 화면(프로젝터·태블릿 1대)으로 할 때 | `/toss/3-1` 처럼 반별 주소 |
| 🎲 온라인 윷놀이 | 학생마다 태블릿으로 들어와 윷판까지 화면에서 진행할 때 | 선생님 `/host`, 학생 `/r/1234` |

### 🥢 윷만 던지기 (실물 윷판용)

- 시작 화면 → **우리 반 윷 던지기** → 학년·반을 고르면 `/toss/3-1` 같은 그 반 전용 화면이 열립니다. 이 주소를 즐겨찾기해 두면 다음에도 바로 열립니다.
- **꾹 눌러 흔들고 놓으면 던집니다.** 흔드는 동안 달그락 소리, 떨어질 때 탁탁 소리, 결과마다 다른 신호음(윷·모는 팡파르, 뒷도는 힝~)이 납니다. 스페이스바·엔터로도 던질 수 있습니다.
- 결과는 **도·개·걸·윷·모·뒷도**를 크게 보여 주고 응원 문구가 따라옵니다. 윷·모는 꽃가루, 모는 화면이 살짝 흔들립니다.
- **차례 관리**: 팀(2~4개)을 정하면 던진 뒤 자동으로 다음 팀으로 넘어가고, 윷·모는 같은 팀이 "한 번 더!" 합니다. 실물 윷판에서 상대 말을 잡았으면 **😈 잡았다! 한 번 더**를 눌러 방금 던진 팀에게 차례를 돌려 줍니다. 팀 이름을 누르면 차례를 직접 바꿀 수 있습니다.
- 설정(⚙️)에서 팀 이름과 **던질 친구 이름 목록**을 적어 두면 "지금 던질 팀 · 민수 친구"처럼 돌아가며 표시합니다. 뒷도(★ 표시 가락) 사용 여부, 효과음, 이 반 주소 QR도 여기 있습니다.
- **반별 격리**: 팀·차례·설정은 반 주소별로 그 기기의 브라우저에 저장됩니다. 여러 반이 같은 서버 주소를 써도, 한 태블릿을 여러 반이 돌려 써도 서로 섞이지 않습니다. 서버와 통신하지 않아 인터넷이 끊겨도 계속 던질 수 있습니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 접속 | 학생은 QR 코드 또는 숫자 4자리 방 코드로 입장 (`/r/1234`) |
| 방 격리 | 방마다 독립된 상태. 다른 반 방에는 코드를 몰라야 들어갈 수 있고, 선생님이 방을 잠글 수 있음 |
| 팀 | 2~4팀 (🐯 호랑이 · 🐰 토끼 · 🐢 거북이 · 🐲 용), 팀당 말 1~4개 |
| 차례 | 팀 안에서 학생들이 **돌아가며** 던짐. 접속이 끊긴 학생은 자동으로 건너뜀 |
| 선생님 화면 | 큰 윷판 + QR + 팀 현황 + 대신 던지기 / 차례 넘기기 / 방 잠금 / 다시 하기 |
| 기술 | Node.js 20, `ws`(WebSocket), 바닐라 JS, 빌드 도구 없음. 데이터베이스 없음(메모리) |

## 수업에서 쓰는 순서

1. 선생님이 배포된 주소를 **프로젝터**로 열고 **게임방 만들기**를 누릅니다. 방 코드(예: `4821`)와 QR 코드가 크게 나옵니다.
2. 팀 수·팀당 말 개수·백도 여부를 정합니다. 40분 수업이면 **2팀 · 말 2개**가 적당합니다.
3. 학생들이 태블릿 카메라로 QR을 찍습니다. 별명을 정하고(진짜 이름 대신 "용감한 다람쥐" 같은 랜덤 별명 제공) 들어오면 가장 인원이 적은 팀에 자동 배정됩니다. 로비에서 팀을 바꿀 수 있고, 선생님도 이름을 눌러 옮기거나 내보낼 수 있습니다.
4. **게임 시작!** 을 누르면 모두의 화면이 게임으로 바뀝니다. 차례인 학생 화면에 큰 **윷 던지기** 버튼이 나오고, 결과 애니메이션은 모든 화면에 함께 보입니다.
5. 말이 여러 개면 학생이 움직일 말을 고릅니다(윷판의 말을 눌러도 되고, 아래 버튼을 눌러도 됩니다). 도착 칸에 ⭐/😈(잡기)/🏁(도착) 표시가 미리 보입니다.
6. 모든 말을 먼저 내보낸 팀이 이기고 축하 화면이 뜹니다. **다시 하기**로 같은 학생들과 바로 새 게임을 시작할 수 있습니다.

선생님 팁
- 학생이 응답하지 않으면 **선생님이 대신 던지기** 또는 **차례 넘기기**를 누릅니다.
- 늦게 온 학생도 QR로 바로 합류합니다. 다 들어왔으면 **방 잠그기**로 다른 반 학생의 오입장을 막습니다.
- 태블릿이 잠겨 연결이 끊겨도 같은 기기에서 다시 열면 같은 학생으로 이어집니다.
- 선생님 화면은 방을 만든 기기에서만 다시 열 수 있습니다(브라우저에 저장된 토큰 사용).

## 게임 규칙

- 윷가락 4개의 배(평평한 면)가 위로 온 개수: **도** 1칸 · **개** 2칸 · **걸** 3칸 · **윷** 4칸 · **모** 5칸(배 0개).
- **윷·모**가 나오면 말을 움직인 뒤 한 번 더 던집니다. (초등 저학년을 위해 "던지기 → 움직이기 → 다시 던지기" 순서로 단순화)
- 상대 말이 있는 칸에 서면 **잡기**: 상대 말은 처음으로 돌아가고 한 번 더 던집니다.
- 우리 말이 있는 칸에 서면 **업기**: 이후 함께 움직입니다(잡히면 함께 돌아갑니다).
- 모서리(5, 10)나 가운데 **방**에 정확히 멈춘 말은 다음 이동 때 **자동으로 지름길**로 갑니다.
- 출발점(20번 위치)에 도달하거나 지나면 **납니다**. 모든 말이 먼저 난 팀이 승리.
- **백도**(선택, 기본 꺼짐): ★ 표시 가락 하나만 배가 위면 뒤로 1칸. 판에 말이 없으면 차례가 넘어갑니다.

윷가락 확률은 배가 위로 올 확률 55%로 두었습니다(`server/game.js`의 `FLAT_PROBABILITY`). 모가 너무 드물지 않게 조정한 값입니다.

## 배포하기 (무료 서버)

서버는 **프로세스 1개**로 동작하며 방 상태는 메모리에 있습니다. 어느 서비스든 **인스턴스 1개**로만 띄우세요. 학교 인터넷은 보통 443 포트만 열려 있으므로 HTTPS(wss)를 제공하는 호스팅을 쓰면 됩니다.

### Render (추천, 무료 플랜)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. [Render](https://render.com) → **New → Blueprint** → 저장소 선택. `render.yaml`이 읽혀 자동으로 설정됩니다. (또는 New → Web Service, Runtime Node, Build `npm ci`, Start `npm start`, Plan Free)
3. 배포가 끝나면 `https://<서비스이름>.onrender.com` 주소가 나옵니다. 이 주소를 선생님들께 알려 주세요.

알아둘 점
- 무료 플랜은 **15분간 접속이 없으면 잠들고**, 첫 접속 때 30~60초 걸립니다. **수업 2~3분 전에 선생님 화면을 먼저 열어 두세요.** 학생이 그 사이 들어오면 잠시 로딩만 보입니다.
- 잠들지 않게 하려면 [cron-job.org](https://cron-job.org) 같은 무료 서비스에서 10분마다 `https://<주소>/healthz`를 호출하게 합니다. 무료 플랜의 월 750시간은 서비스 1개를 24시간 켜 두기에 충분합니다.
- 재배포·재시작이 일어나면 진행 중인 방이 사라집니다. 수업 중 갱신하지 마세요.

### 다른 선택지

- **Koyeb**: `Dockerfile`이 있으므로 GitHub 연결 → Docker 빌드로 배포. 무료 인스턴스 1개 제공(정책은 수시로 바뀌니 확인).
- **Fly.io / Railway**: 같은 `Dockerfile`로 배포 가능. 소액 과금 또는 체험 크레딧 기반.
- **직접 운영(학교 서버·라즈베리파이)**: `npm ci --omit=dev && PORT=3000 npm start`. 학생 기기가 같은 Wi-Fi에 있으면 인터넷 없이도 됩니다. HTTPS가 없으면 `http://<IP>:3000`으로 접속(QR도 그 주소로 생성됨).

환경 변수
- `PORT` — 서비스가 넘겨주는 포트. 기본 3000.
- `PUBLIC_URL` — QR/입장 링크에 쓸 공개 주소. 비우면 프록시 헤더(`x-forwarded-proto`, `host`)로 추정합니다. 주소가 이상하게 나오면 이 값을 고정하세요.

## 로컬 실행과 테스트

```bash
npm install
npm start          # http://localhost:3000
```

```bash
npm test           # 규칙 엔진 단위 테스트 + WebSocket 프로토콜 통합 테스트 (node:test)
```

같은 컴퓨터에서 선생님·학생을 함께 시험하려면 브라우저 두 종류(또는 일반 창 + 시크릿 창)를 쓰세요. 한 브라우저의 탭들은 저장소를 공유해 선생님/학생 세션이 섞일 수 있습니다.

## 구조

```
server/
  index.js     진입점 (PORT 로 listen)
  app.js       HTTP 정적 파일 · /qr/:code.svg · /healthz · WebSocket 업그레이드
  protocol.js  WebSocket 메시지 처리 (선생님/학생 인증, 차례 학생 선정, 속도 제한, 상태 브로드캐스트)
  rooms.js     방·학생 관리 (4자리 코드, 토큰, 잠금, 2시간 비활성 정리)
  game.js      윷놀이 규칙 엔진 (순수 함수: 던지기 판정, 경로·지름길, 잡기·업기, 승리)
public/
  index.html      단일 페이지
  js/app.js       클라이언트 (라우팅 · 재접속 · 상태 큐/애니메이션 · 화면 렌더링)
  js/board.js     윷판 SVG (29칸 좌표, 말 이동 트랜지션, 선택 힌트)
  js/toss.js      윷 던지기 전용 모드 (반별 localStorage 상태, 흔들기·던지기 연출, 팀 차례)
  js/toss-rules.js 윷 던지기 판정 (서버 game.js 와 공유)
  js/sound.js     Web Audio 합성 효과음
  css/style.css
test/
  game.test.js      규칙 엔진
  protocol.test.js  서버를 임의 포트로 띄워 선생님 1명 + 학생 3명이 끝까지 플레이, 재접속·남용 방어 검사
  rooms.test.js     방 정리(빈 방 10분, 로비 유령 학생 2분), 코드 재사용, 별명 정제
```

윷판 칸 번호: 바깥 둘레 1~19(출발점에서 시계 반대 방향), 20 = 도착. 5→방→15 지름길은 21·22·23(방)·24·25, 10→방→20 지름길은 26·27·23·28·29. 말은 `(lane, index)`로 위치를 기억해 지름길 진입·백도 되돌아가기를 정확히 처리합니다.

WebSocket 메시지 종류는 `server/protocol.js` 상단 주석에 정리되어 있습니다.

## 운영 메모

- **개인정보**: 별명만 받고 서버 메모리에만 두며, 방은 마지막 접속 후 2시간이 지나면 지워집니다. 로그에도 별명을 남기지 않습니다. 안내 문구로 진짜 이름 대신 별명을 쓰도록 유도합니다.
- **제한**: 방 최대 500개, 방당 학생 60명, 메시지 16KB. 방 코드는 숫자 4자리라 추측이 가능하므로, 학생이 다 들어오면 **방 잠그기**를 권장합니다(잠기면 팀 바꾸기도 막힙니다).
- **남용 방어**: 연결당 초당 20개 메시지(버스트 30), 없는 방 코드 5회 입력 시 연결 종료, 연결당 방 3개·IP당 10분에 50개까지 생성. 학생이 없는 빈 방은 10분, 로비에서 끊긴 채 2분이 지난 학생은 명단에서 자동 정리됩니다.
- **서버 재시작 뒤**: 선생님 화면에 "방 코드 ○○○○로 다시 만들기" 버튼이 나옵니다. 같은 코드로 다시 만들면 이미 나눠 준 QR·방 코드를 그대로 쓸 수 있고, 학생들은 QR을 다시 찍어 들어옵니다.
- **차례 학생 이탈**: 던질 학생의 접속이 끊기면 5초는 기다렸다가 같은 팀 다른 학생에게 넘깁니다. 아무도 없으면 선생님이 대신 던집니다. 다시 시작할 때마다 먼저 던지는 팀이 바뀝니다.
- **동시 접속**: 학교 한 곳(학급 6~10개, 학생 300명)이 동시에 써도 무료 인스턴스로 충분한 규모입니다.
